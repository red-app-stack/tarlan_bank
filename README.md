## О проекте

**Tarlan Bank** — мобильное банковское суперприложение на Flutter: счета и карты, переводы и платежи, курсы валют, инвестиционный раздел и ИИ-помощник. Проект создан для **[Hackathon 2026]** как прототип банка для молодой аудитории: быстрый, понятный и безопасный.

> Это демонстрационный прототип, а не реальный банк: реальные деньги не переводятся, данные тестовые.

---

## Проблема и решение (Hackathon 2026)

### Проблема

- **Банковские приложения неудобны.** Много экранов и шагов ради простого перевода, перегруженный интерфейс, термины, которые непонятны новичку.
- **Новички боятся инвестировать.** Из-за неопытности и эмоций люди сливают деньги, а мир инвестиций кажется «только для профи».
- **Молодёжь 18–35 лет** привыкла к современным сервисам: удобство и технологичность для них важнее старомодного банкинга, а удобных вариантов фактически нет.

### Наше решение

1. **Банк, которым приятно пользоваться.** Современный стеклянный UI, светлая и тёмная темы, адаптивные отступы, три языка (русский, английский, казахский), короткие сценарии платежей и переводов — включая перевод по QR.
2. **Надёжная защита.** Firebase Auth (почта/пароль и Google), подтверждение почты, обязательное заполнение профиля, код доступа, биометрия и активная проверка лица прямо на устройстве (ML Kit, видео не сохраняется), правила Firestore и защищённое хранилище.
3. **ИИ-помощник Tarlan Assistant.** Отвечает о картах, платежах, вкладах и кредитах, объясняет продукты простым языком и помогает новичку сделать первый шаг без страха. Ответы потоковые (SSE); следующий шаг продукта — подбор портфеля под цель и риск-профиль пользователя.

**Целевая аудитория:** молодые люди 18–35 лет, которые хотят попробовать инвестиции без риска и ценят удобство вместо старомодного банкинга.

## Что работает в демо

- **Счета и карты:** несколько счетов, стартовая дебетовая карта с тестовым балансом, детали карты, история операций.
- **Переводы:** по номеру телефона, между своими счетами, на карту, по QR-коду, конвертация валюты.
- **Платежи:** коммунальные услуги, интернет, связь, транспорт и другие сервисы, история платежей (только демо).
- **Курсы валют** на главном экране, обзор рынка в разделе инвестиций.
- **ИИ-чат** с потоковым ответом ассистента и переключением локального/удалённого бэкенда.
- **Безопасность:** вход по почте и через Google, верификация почты, заполнение профиля, PIN, биометрия, проверка лица с активной «живостью» на устройстве, повторная аутентификация для чувствительных действий.
- **Локализация:** русский, английский и казахский языки (`lib/l10n`, `flutter gen-l10n`).

## Архитектура и стек

Слои: `views` (экраны и общие виджеты) → `features` (данные и провайдеры предметной области) → `services` / `core` (Firebase, сеть, безопасность, роутинг, уведомления, темы).

- **Flutter 3.50.1 / Dart 3.14.0**, кроссплатформенный UI (Android, iOS); веб- и десктоп-цели не заявлены.
- **Состояние и навигация:** `flutter_riverpod` + `go_router` (StatefulShellRoute), единый `ProviderContainer`.
- **UI:** `material_ui`, `liquid_glass_easy`, `cupertino_ui`, own темы и переиспользуемые виджеты в `lib/views/shared`.
- **Бэкенд:** Firebase Auth, Cloud Firestore, Cloud Messaging, локальные уведомления; правила и индексы Firestore лежат в `firestore.rules` / `firestore.indexes.json`.
- **Чат/ИИ:** `AiChatRepository` с потоковым ответом, SSE-клиент на Dio, резервный локальный/удалённый канал.
- **Тесты:** `flutter test` (юнит- и виджет-тесты в `test/`).

## Быстрый старт

Требуется Flutter 3.50+ (Dart 3.14+) и настроенный Android SDK или симулятор.

```bash
git clone https://github.com/red-app-stack/tarlan_bank.git
cd tarlan_bank
flutter pub get
flutter gen-l10n
flutter test
flutter run
```

Для полноценного запуска нужен собственный Firebase-проект: добавьте конфиги платформ (`google-services.json` / `GoogleService-Info.plist`), включите нужные провайдеры аутентификации и разверните правила Firestore. Адрес бэкенда чата задаётся переменной `BANK_API_URL` в файле `.env`, который подключается через `flutter_dotenv`. Без бэкенда остальной функционал работает на тестовых данных Firestore.

Проверки перед коммитом:

```bash
dart format .
flutter analyze
flutter test
```

<details>
<summary><strong>Сборка своего APK</strong></summary>

```bash
flutter pub get
flutter build apk --debug
```

Готовый файл: `build/app/outputs/flutter-apk/app-debug.apk`.

</details>

## Структура репозитория

```
lib/
  core/        # роутинг, провайдеры, Firebase, безопасность, сервисы, темы, локализация
  features/    # счета, авторизация, чат, курсы, платежи, переводы
  services/    # сеть, хранилище, уведомления, LLM/SSE-клиент
  views/       # экраны и переиспользуемые виджеты
  l10n/        # переводы *.arb (ru, en, kk)
test/          # юнит- и виджет-тесты
.md/CHANGES.md # журнал изменений
```
